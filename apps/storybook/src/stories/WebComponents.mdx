# Web Components

Custom elements for all ISO 7001 public information symbols — framework-agnostic, works with any HTML page or JavaScript framework.

## Installation

```sh
npm install @public-information-symbols/elements
```

## Setup

Call `defineCustomElements()` once at app startup to register all custom elements:

```ts
import { defineCustomElements } from '@public-information-symbols/elements';
defineCustomElements();
```

---

## Generic element — `<pi-symbol>`

Renders any symbol by slug ID. Use this when the symbol ID is dynamic or unknown at build time.

```html
<pi-symbol symbol-id="ac-001-full-accessibility-or-toilets-accessible" width="64"></pi-symbol>
```

```ts
import { defineCustomElements } from '@public-information-symbols/elements';
defineCustomElements();
```

### Attributes

| Attribute | Type | Default | Description |
| --------- | ---- | ------- | ----------- |
| `symbol-id` | `string` | — | Slug ID, e.g. `ac-001-full-accessibility-or-toilets-accessible` |
| `width` | `string \| number` | SVG intrinsic | Width forwarded to the `<svg>` element |
| `height` | `string \| number` | SVG intrinsic | Height forwarded to the `<svg>` element |
| `title` | `string` | Symbol name | Overrides the accessible `<title>` |
| `description` | `string` | Symbol description | Overrides the accessible `<desc>` |

---

## Named elements

Each symbol has its own named element — e.g. `<pi-ac-001-full-accessibility-or-toilets-accessible>`. Named elements accept the same `width`, `height`, `title`, and `description` attributes.

```html
<pi-ac-001-full-accessibility-or-toilets-accessible width="64"></pi-ac-001-full-accessibility-or-toilets-accessible>
<pi-pf-001-general-information width="64"></pi-pf-001-general-information>
```

## Usage in frameworks

### Vue 3

```vue
<script setup>
import { defineCustomElements } from '@public-information-symbols/elements';
defineCustomElements();
</script>
<template>
  <pi-symbol symbol-id="ac-001-full-accessibility-or-toilets-accessible" width="64" />
</template>
```

### Angular

```ts
// app.module.ts
import { CUSTOM_ELEMENTS_SCHEMA, NgModule } from '@angular/core';
import { defineCustomElements } from '@public-information-symbols/elements';
defineCustomElements();

@NgModule({ schemas: [CUSTOM_ELEMENTS_SCHEMA] })
export class AppModule {}
```
