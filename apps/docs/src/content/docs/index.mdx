## Why Public Information Symbols?

ISO 7001 defines public information symbols used in transport hubs, public buildings, hotels,
and civic spaces worldwide — from accessibility icons to toilet signs, from airport symbols to
restaurant indicators. This library packages all 178 symbols as accessible, fully typed components.

<CardGrid>
  <Card title="React & Vue 3" icon="puzzle">
    Named components and a `SymbolById` helper for dynamic rendering. Tree-shakeable — only the
    symbols you import end up in your bundle.
  </Card>
  <Card title="Web Components" icon="laptop">
    Framework-agnostic Custom Elements. Works with Angular, Svelte, plain HTML — anywhere.
  </Card>
  <Card title="CSS Sprite" icon="seti:css">
    Zero JavaScript option. Display any symbol with a single class and no JS runtime.
  </Card>
  <Card title="Accessible by default" icon="approve-check-circle">
    Every component renders with `role="img"`, `aria-labelledby`, `<title>`, and `<desc>` inside
    the SVG.
  </Card>
</CardGrid>
