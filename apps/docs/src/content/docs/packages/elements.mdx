## Installation

```sh
npm install @public-information-symbols/elements
```

## Registering elements

Call `defineCustomElements()` once at your application entry point to register all custom elements with the browser.

```ts
import { defineCustomElements } from '@public-information-symbols/elements';

defineCustomElements();
```

### Custom prefix

By default elements are registered under the `pi-` prefix. Pass a different prefix to register them under another name as well; each prefix can be registered alongside the others.

```ts
defineCustomElements('my');
// registers <my-ac-001-full-accessibility-or-toilets-accessible>
```

## Generic element

Use `<pi-symbol>` when the symbol is not known at build time.

```html
<pi-symbol
  symbol-id="ac-001-full-accessibility-or-toilets-accessible"
  width="64"
  title="Accessible toilets"
></pi-symbol>
```

## Named elements

Every symbol also has a dedicated tag derived from its ID.

```html
<pi-ac-001-full-accessibility-or-toilets-accessible
  width="64"
  title="Accessible toilets"
></pi-ac-001-full-accessibility-or-toilets-accessible>
```

## Attributes

| Attribute      | Type     | Required for `<pi-symbol>` | Description                                               |
| -------------- | -------- | -------------------------- | --------------------------------------------------------- |
| `symbol-id`    | `string` | Yes                        | Symbol ID (only used on the generic `<pi-symbol>`).       |
| `width`        | `string` | No                         | Width of the rendered SVG in pixels.                      |
| `height`       | `string` | No                         | Height of the rendered SVG in pixels.                     |
| `symbol-title` | `string` | No                         | Accessible name injected as `<title>` in the SVG.         |
| `title`        | `string` | No                         | Same as `symbol-title`, but also shows a browser tooltip. |
| `aria-label`   | `string` | No                         | Explicit accessible name, forwarded to the `<svg>`.       |
| `description`  | `string` | No                         | Longer description injected as `<desc>` in the SVG.       |

## Reactivity

Attributes are observed. Updating them via JavaScript causes the SVG to re-render automatically.

```js
const el = document.querySelector('pi-symbol');
el.setAttribute('symbol-id', 'pf-001-toilets');
el.setAttribute('width', '128');
```

## Accessibility

Every element announces the symbol name by default; use `symbol-title` or `aria-label` to override it. The `<svg>` gets `role="img"` and `aria-labelledby` pointing to its `<title>`, plus `aria-describedby` when a distinct description is set. For purely decorative symbols, set `aria-hidden="true"` on the element.
